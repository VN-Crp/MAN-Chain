# MAN Chain Security Policy

This is an early-stage project. Do not use experimental code or testnet with real funds.

Security priorities include private-key safety, transaction replay protection, consensus safety, state transition correctness, denial-of-service resistance, supply/vesting invariants, governance controls, dependency review, and signed releases.

Mainnet must not launch before independent review, resolution of critical/high findings, reproducible builds, and tested incident response.
