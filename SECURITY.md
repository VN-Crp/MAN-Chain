# MAN Chain Security Policy

MAN Chain is an early-stage project. Do not use experimental code or any future testnet with real funds.

Security priorities include private-key safety, transaction replay protection, consensus safety, state transition correctness, denial-of-service resistance, supply and vesting invariants, governance controls, dependency review, and signed releases.

Mainnet must not launch before independent review, remediation of critical/high findings, reproducible builds, and tested incident response.
