# MAN Chain Roadmap

1. **Foundation:** website, repository, draft tokenomics and public documentation.
2. **Protocol specification:** consensus, accounts, transaction format, gas, validators, staking, epochs and unbonding.
3. **Local development network:** multiple nodes, deterministic execution, automated tests and state recovery.
4. **Public testnet:** public node instructions, RPC, monitoring, faucet policy, load testing and upgrade rehearsals.
5. **Security readiness:** independent review, fix critical/high issues, test incident response and verify genesis parameters.
6. **Mainnet:** only after technical, operational, security and legal launch gates pass.
7. **Wallet and ecosystem:** release audited wallet builds and expand integrations in stages.

All stages are planned; none should be marked complete without evidence.
