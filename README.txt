MAN Chain — landing page

Files:
- index.html: page structure and Vietnamese content
- styles.css: layout, responsive styling, colors and visual effects
- script.js: mobile navigation menu

How to preview:
1. Extract the ZIP.
2. Open index.html in a modern browser. Internet access is used only to load the Inter font from Google Fonts; system sans-serif fallback is included.
3. To publish with GitHub Pages, upload these files to the repository root and enable Pages in repository settings.

Notes:
- The roadmap timeline section has intentionally been removed, per request.
- The hero city/globe, wallet and dashboard are recreated using CSS/SVG-style HTML elements, not the original 3D artwork. This is a close visual recreation from the screenshot, not a pixel-perfect copy of the original design assets.
- Navigation items are visual anchors/placeholders unless their target section exists.
