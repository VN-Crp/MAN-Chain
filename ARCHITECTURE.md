# MAN Chain Architecture — Draft

MAN Chain is a proposed independent blockchain. This document is a draft, not a deployed protocol.

## Components
- Node and peer networking
- Consensus and validator lifecycle
- Deterministic state machine and transaction validation
- Gas and fee accounting
- Wallet, explorer, monitoring, and governance

## Required before public testnet
Publish a protocol specification, reproducible build, multi-node tests, telemetry, upgrade process, and incident response plan.

## Required before mainnet
Independent security review, resolution of critical findings, validator operations rehearsal, verified genesis allocations, and legal review.
