# MAN Chain Architecture — Draft

MAN Chain is a proposed independent blockchain. This document describes an early direction, not a deployed network.

## Planned components
- Peer-to-peer node networking
- Consensus and validator lifecycle
- Deterministic transaction execution and state storage
- Gas and fee accounting
- Wallet, explorer, monitoring, and governance interfaces

## Before testnet
Publish protocol specifications, reproducible builds, multi-node tests, metrics, and an upgrade plan.

## Before mainnet
Complete independent security review, resolve critical/high findings, rehearse validator operations, verify genesis parameters, and review legal requirements.
